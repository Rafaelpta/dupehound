dupehound

Finds functions duplicated by AI, even after every identifier is renamed.

It fingerprints the structure of your code instead of its text, so two functions that do the same thing get caught even when every name and literal is different. Fast, offline, no AI required.

dupehound scan 
$ dupehound scan ./src

  dupehound — scanned 2 files · 24 lines · 2 functions in 30ms

  SLOP SCORE  41.7%   grade F
  10 of 24 significant lines are deletable duplicates

  ● Cluster 1 — 2 copies · 100% similar · 10 deletable lines
    ★ A.cs:2  ComputeTotal      10 lines
      B.cs:2  CalculateAmount   10 lines   100% █████████

  slop score = lines deletable if every cluster kept one copy
$ cargo install dupehound

Prebuilt binaries for macOS, Linux and Windows on the releases page, or brew install rafaelpta/dupehound/dupehound.

scanreports every duplicate cluster and a repo-level slop score
historycharts duplication across the git log and pinpoints when it took off
checkfails CI when a change duplicates code that already exists, naming the original to reuse

Coding agents don't know what a codebase already contains, so they rewrite it. GitClear found duplicated code blocks grew 8x in 2024. dupehound is the deterministic side of the loop: the agent writes, the index remembers.
